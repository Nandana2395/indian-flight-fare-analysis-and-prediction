# Indian Flight Fare Analysis and Prediction

## Overview
This project analyzes Indian domestic flight fare data and develops machine learning models to predict flight ticket prices. The project includes data preprocessing, exploratory data analysis, feature engineering, model training, hyperparameter tuning, and performance evaluation.

## Dataset
The dataset contains information about Indian domestic flights, including:

- Airline
- Source
- Destination
- Date of Journey
- Departure Time
- Arrival Time
- Duration
- Total Stops
- Additional Information
- Ticket Price (Target Variable)

## Project Objectives
- Clean and preprocess flight data
- Perform exploratory data analysis
- Engineer useful features
- Train multiple regression models
- Compare model performance
- Select the best prediction model

## Key Findings
- Airline significantly influences ticket prices.
- Number of stops impacts airfare.
- Journey duration strongly affects ticket cost.
- Advance booking generally results in lower fares.
- Ensemble models outperform simple regression models.
